# 蓝色大肥鱼 · 1.1.24

桌宠运行时不再显示独立任务栏按钮，托盘图标保持不变；打开设置等普通窗体时仍会显示在任务栏。桌宠保留可供外部采集程序枚举的窗体样式。

Windows 标准版下载 `BigBlueFish-v1.1.24-OCR-Setup.exe`，无 ACP 版下载 `BigBlueFish-v1.1.24-Safe-OCR-Setup.exe`；Ubuntu／Debian x64 标准版下载 `BigBlueFish-v1.1.24-Linux-x64.deb`，无 ACP 版下载 `BigBlueFish-v1.1.24-Safe-Linux-x64.deb`。文件名中的 `Safe` 对应无 ACP 版，各安装包均提供配套 `.sha256` 校验文件。已安装的用户可以在设置中检查更新直接升级，也可以手动运行新版安装器；Windows 上选择原安装目录即可保留模型与设置。
